# 读回验收报告模板（readback_report.md）

> sr-config skill 附带。每次写入工作簿后的验收报告**必须**逐条对照本模板，
> 每项标注 `pass | fail | not_applicable`（附证据定位），缺项或 `not_run` 一律按 `fail` 计。
> **禁止自拟另一套"全部通过"式清单替代本模板**——验收项以模板为准逐条映射，
> `pass` 的总数再多，也不能替代任何一项必达的 `fail`/缺失。

## 报告头

- 任务分支：create_workbook | schema_change | record_change
- 目标文件：绝对路径（含 sha256）
- 源文件/来源文档：路径 + sha256（无则写"无"）
- 备份文件：路径（新建文件写"无（新建）"）
- 临时文件与处置：已替换 / 已保留为 .failed.（验收失败时）
- 报告生成时间与生成方式（脚本名或人工核对）

## 必达项对照（逐条填写，对应 mutation 语义的硬性清单）

| # | 验收项 | 结果 | 证据/定位 |
| --- | --- | --- | --- |
| 1 | 目标文件与写入范围内工作表 100% 存在 | | |
| 2 | change set 中的 change 100% 可读回（每条 change 一行） | | |
| 3 | 变更字段五行表头 100% 等于已确认 schema（逐列） | | |
| 4 | 变更记录键与 before/after 100% 匹配 | | |
| 5 | 主键与索引唯一性 100% 通过 | | |
| 6 | 必填值、枚举、单位、边界、空值规则 100% 通过 | | |
| 7 | codec 字段逐值 parse→validate→serialize→parse 通过 | | |
| 8 | 纳入范围的引用解析率 100%（含外部引用真实存在） | | |
| 9 | INDEX、配置说明、**字段批注**写入项 100% 匹配 | | |
| 10 | 新表测试记录/主键/引用/fixture_coverage 100% 匹配 | | |
| 11 | 无计划外配置数据差异（diff 集合 == change set） | | |

## 追加项（视源文件特性适用，不适用写 not_applicable）

## 结论

- 状态：PASS（全部必达 pass 且无 open blocker） / BLOCKED（任一 fail）
- blocker 清单：编号 / 摘要 / 影响的 change / 恢复方式
- deferred 清单：编号 / 摘要 / 是否影响已写入数据正确性（必须为否）
- 未覆盖范围声明（"工具执行成功"≠"验收成功"）
