# sr-gdd-human

功能 GDD 工作流（人类可读版）：以《神话宝库_合并定稿_20260828》为形态范本，产出只含设计结果的功能开发文档——不生成配置契约、不留证据/拍板/治理等过程性内容，重点保证功能规则详细且可读、界面流程完整到位。

用法：`/sr-gdd-human <主题或材料路径>`

两条硬约束：

1. **不把配置数值当规则**——正文只写机制（配置字段名只作指代），把配置表数字任意改一遍，正文应一字不用改；
2. **只保留当前口径**——不写新旧对照与“本次已改”式历史表述，废弃口径只在文末用一句话追溯。

与 `sr-gdd`（完整溯源版）的区别见 SKILL.md「与 sr-gdd 的关系」。
