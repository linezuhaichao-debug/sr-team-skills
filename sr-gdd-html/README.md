# sr-gdd-html

评审宣讲 HTML 工作流：把**已经定稿**的功能 GDD（`sr-gdd` / `sr-gdd-human` 的产出，或任意既有策划案 md）重排成评审会/宣讲会用的**单文件自包含 HTML**——一个界面一节、左图右文、规则块化，截图 base64 内嵌、零外链，可直接投屏、可直接外发。

用法：`/sr-gdd-html <GDD 路径或主题>`

三条硬约束：

1. **只搬运，不发明**——规则/数值/边界全部来自源 GDD；源 GDD 没写的标"待定"，不替策划补规则、不臆造数值；html 是派生物，任何修订都回到 `content.json` 重跑，不手改 HTML。
2. **只放最终规则**——确认编号（Q1/Q2…）、用户原话、"拍板 / 已确认 / 跟推荐"等过程措辞一律不出现；不放文本 ID 清单。
3. **单文件自包含**——图片 base64 内嵌，禁 `https://` 外链、禁 `./assets/` 散装目录；有图给图、无图给指路占位框，不留空。

与 `sr-gdd` / `sr-gdd-human` 的分工见 SKILL.md 的「与 sr-gdd / sr-gdd-human 的关系」：前两者**生产设计结论**（输出 md），本 skill **不生产结论**，只把 md 重排成会上能讲的页面。

## 目录

| 路径 | 作用 |
| --- | --- |
| `SKILL.md` | 执行流程（输入确认 → 结构抽取 → 截图准备 → 红线校验 → 渲染 → 视觉冒烟 → Human Gate） |
| `resources/toolkit/` | **原样内置**的渲染工具包：固定验收模板、通用生成器 `gen_01.py`、双栏版式规范、工具包 README |
| `resources/PROVENANCE.md` | 工具包来源、逐文件 sha256、再同步方式、未入库项说明 |
| `tools/lint_content.py` | 本 skill 自研的内容红线 + 结构校验器（生成器之前必跑） |
| `tools/smoke_check.mjs` | 本 skill 自研的视觉冒烟检查器：无头浏览器跑五项判定 + 整页截图（Node ≥ 22，无第三方依赖） |
| `examples/合成示例/` | 合成形态基准（content.json + 占位截图 + 生成的 HTML），无真实项目数据 |

## 为什么自包含一个工具包

`resources/toolkit/` 来自 AI_SR 交互交付流程的「宣讲 HTML 生成工具包」（2026-09-10 版），与团队既有交付物 `01_宣讲会交付.html` 同规格。原样内置的好处是**离线可复现同一套视觉**、不依赖任何人本机路径；代价是仓库多出工具包体积。工具包 README 自己提醒"拷贝文件夹当技能装会跟源头漂移"，因此本目录**只读**，更新时按 `PROVENANCE.md` 的 sha256 整体替换。
