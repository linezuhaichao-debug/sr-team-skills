# 图外标注模块

本模块用于交互设计文档中的“参考图 + 交互说明”表达，并保留一个仅按明确需求启用的图外标注模式。

它不是独立工具，而是一套文档写法和图片标注约定。无论参考图来自本地图片、图片网址、原型工具导出图，还是已经置入文档的图片，都按同一套结构组织。

> **默认关闭视觉标记**：未收到用户当前任务的明确要求时，保留干净原型图，在正文直接使用可见控件名称；不得添加字母、数字、圈号、图号、徽标或引线。下文第 3～9 节中的标注细则仅在用户明确要求“需要标记/编号/引线”后生效，历史模板和旧案例不能自动启用。

## 1. 使用场景

参考图与双栏说明可在以下场景使用；其中的字母/数字/引线标注仍需用户明确启用：

- 原型图中的关键交互控件需要和右侧说明一一对应，默认直接写控件名。
- 需要保留完整界面原型，同时说明局部控件含义。
- 不希望把控件名称、规则文案或大段说明压在图片上。
- 文档预览环境对复杂覆盖层、绝对定位或交互式标注支持不稳定。
- 需要稳定交付“左侧参考图 / 右侧交互说明”的阅读结构。

如果任务只是交互回写 MD、文本 ID 清单或策划确认，不启用本模块的视觉标记。

不适用场景：

- 界面流程图中的界面缩略图：流程图只表达页面流转，缩略图应优先使用无标注的干净界面图。
- 只说明规则、不需要图片控件对应关系的文本段落。

## 2. 基本版式

参考图和交互说明使用左右双栏。

- 左侧：参考图，占 50%。
- 右侧：交互说明，占 50%。
- 左侧参考图必须保持完整界面，不裁成控件局部图。
- 左侧参考图默认使用干净原图。
- 只有用户明确启用标注模式时，才可以使用已加图外标注的完整界面图。
- 标注模式启用后，具体标记类型以用户要求为准；用户未指定时先确认，不自行选择字母或数字体系。
- 控件名称、展示规则、点击反馈、异常处理写在右侧说明中，不写在图片上。

```
<table style="width:100%; table-layout:fixed;">
  <colgroup>
    <col style="width:50%;">
    <col style="width:50%;">
  </colgroup>
  <thead>
    <tr>
      <th width="50%" style="width:50%; text-align:left; vertical-align:top;">参考图</th>
      <th width="50%" style="width:50%; text-align:left; vertical-align:top;">交互说明</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td width="50%" style="width:50%; vertical-align:top;">
        <img src="data:image/png;base64,..." alt="界面名称_图外标注" width="100%" style="width:100%; height:auto; display:block;">
      </td>
      <td width="50%" style="width:50%; vertical-align:top;">
        <strong>进入后的默认表现</strong><br>
        说明该界面的默认展示状态。<br><br>

      </td>
    </tr>
  </tbody>
</table>
```

## 3. 图上标注内容规则

本节仅在用户明确启用视觉标记后适用。

- 标注必须放在图片外侧，不直接压在控件上。
- 图上只显示字母：`A`、`B`、`C`。
- 图上不显示圆圈。
- 图上不写“规则入口”“购买按钮”等控件名称。
- 图上不写规则、提示文案、交互说明或补充解释。
- 字母必须和右侧说明一一对应。
- 一张图中的字母顺序按阅读路径或操作路径排列，优先从上到下、从左到右。

## 4. 标注位置规则

本节仅在用户明确启用视觉标记后适用。

标注可以分布在界面上、下、左、右四个方向，不局限于左右两侧。

选择标注方向时按以下优先级判断：

1. 离目标控件最近。
2. 能与控件落点水平或垂直对齐。
3. 不遮挡核心文案、价格、按钮文字、奖励数量和关键图标。
4. 不与其他标注线交叉。
5. 多个标注能形成稳定的对齐队列。

对齐规则：

- 左侧标注文字右对齐，形成右侧隐形参考线。
- 右侧标注文字左对齐，形成左侧隐形参考线。
- 顶部标注文字居中对齐，标注线从文字中心轴向下连接。
- 底部标注文字居中对齐，标注线从文字中心轴向上连接。
- 多个标注纵向排列时，保持一致行间距。
- 多个顶部或底部标注并列时，保持同一水平基线。
- 标注文字与原型控件或界面边缘保持 `8px-16px` 的最小视觉间距，避免紧贴控件、边缘或其他标注。

## 5. 标注线规则

本节仅在用户明确启用视觉标记后适用。

标注线用于连接字母和控件，必须遵守以下规则。

基础样式：

- 颜色固定为 `#F02864`。
- 线宽固定为 `2px`。
- 线型固定为实线。
- 不使用箭头、圆点、圆圈或端点装饰。

连接顺序：

1. 优先使用水平直线或垂直直线。
2. 能通过调整标注文字位置，让标注文字中心线与控件落点水平 / 垂直对齐时，不允许使用斜线。
3. 左右侧标注使用水平线连接：标注文字中心线与控件落点保持同一水平线。
4. 顶部 / 底部标注使用垂直线连接：标注文字中心轴与控件落点保持同一垂直线。
5. 不能水平 / 垂直对齐时，使用水平 / 垂直转折线。
6. 使用转折线时，只允许水平段和垂直段，不允许斜线。
7. 只有水平 / 垂直直线无法满足排列、会交叉、会遮挡关键内容或会导致标注过于拥挤时，才使用转折线。

落点规则：

- 引线落点选择控件距离图片边界最近的一侧。
- 落点应落在控件外接边缘或边缘附近，不落在控件中心点。
- 落点不要压住核心文案、价格、按钮文字、奖励数量或关键图标。

交叉规则：

- 标注线原则上不允许线与线之间交叉。
- 若截图空间极端受限，必须先调整字母位置、标注方向、落点或拆分标注图。
- 只有无法通过上述方式解决时，才允许进入转折线方案；转折线仍必须避免交叉。

## 6. 字母和说明对应规则

本节仅在用户明确要求使用字母对应时适用；若用户指定数字或其他体系，先按用户要求调整，不从本文件推断。

右侧说明用字母和控件名称建立对应关系。

```
**A：规则入口**
展示规则说明入口。点击后打开规则说明弹窗，具体文案以配置为准。

**B：活动倒计时**
展示活动剩余时间。进入界面或定时刷新；活动结束后入口隐藏。

**C：购买按钮**
未购买时展示。点击后进入购买确认流程。
```

写法要求：

- 字母必须和图上的字母一致。
- 控件名称写在正文里，不写在图上。
- `包含内容` 只列当前界面对象，不写交互规则。
- 每个控件只描述玩家可感知的展示、点击反馈、跳转结果和异常状态。
- 程序规则、支付幂等、补发机制、配置表字段等内容不要塞进控件说明，放到规则补充或待确认项。

## 7. 图片来源处理

图片承载按载体区分（与 `interaction-deliverable-packaging` 4.1 图片承载边界一致），本模块产出的图外标注副本是**独立 HTML 载体**：

### 标注副本（独立 HTML）

图片一律 base64 内嵌，保证单文件可独立打开、单独发送不丢图：

```
<img src="data:image/png;base64,..." alt="界面名称_图外标注" width="100%" style="width:100%; height:auto; display:block;">
```

### 02 交互回写 MD 内引用标注副本

若标注副本随 ZIP 交付且需在 02 MD 中引用，用 `截图/` 相对路径（标注副本文件须归入 `截图/` 并遵守两位序号命名）：

```
![界面名称_图外标注](截图/05_界面名称_图外标注.png)
```

### 禁止外链与散装资源目录

- 不使用 `https://` 外链图片：外链会过期、离线丢失，且违反独立 HTML 自包含要求。
- 不使用 `./assets/` 等散装相对路径目录：02 MD 只允许 `截图/` 相对路径，独立 HTML 只允许内嵌。
- 图外标注副本**没有**"HTML+资源目录"例外（该例外只属于 `interaction-confirmation-sheet` 的确认单）：需要连资源目录才能打开的标注稿只能算非正式过程文档，不得作为正式交付物；正式交付一律 base64 自包含。

### 原型工具链接

原型工具页面链接不是图片地址，不能直接当作图片显示。

推荐处理方式：

1. 从原型工具导出截图或切图。
2. 标注后按上述载体规则内嵌（独立 HTML）或归入 `截图/`（02 MD 引用）。
3. 再按本模块的图外标注规则处理。

## 8. 标注索引表

仅在用户明确启用视觉标记且一张图里的控件较多时，可在图片下方或说明前增加索引表；默认模式不生成标注索引表。

| 标注 | 控件 | 说明位置 | 备注 |
| --- | --- | --- | --- |
| A | 规则入口 | A：规则入口 | 点击后打开规则说明 |
| B | 活动倒计时 | B：活动倒计时 | 活动结束后隐藏 |
| C | 购买按钮 | C：购买按钮 | 未购买状态展示 |

## 9. 交付检查

交付前逐项检查：

- 图片能正常预览，无乱码、无破图。
- 若本轮明确要求图外标注，输出文档中的原型图均已按用户指定体系完成；未要求时必须交付干净原图，并检查不存在字母、数字、圈号、徽标或引线叠加。
- 左侧参考图约占 50%，右侧说明约占 50%。
- 参考图保持完整界面，不是控件局部裁切图。
- 图上只有字母和标注线，没有圆圈、说明文字或规则文本。
- 字母与右侧说明一一对应。
- 标注线为 `#F02864`、`2px`、实线。
- 标注线优先为水平直线或垂直直线。
- 左右侧标注线与控件落点水平对齐。
- 顶部 / 底部标注线与标注文字中心轴、控件落点垂直对齐。
- 没有斜线；不能水平 / 垂直对齐时，才使用水平 / 垂直转折线。
- 转折线只由水平段和垂直段组成。
- 标注文字与控件或界面边缘保持 `8px-16px` 的最小视觉间距。
- 多个纵向标注行间距一致，左右侧文字左对齐或右对齐形成隐形参考线。
- 顶部 / 底部标注居中对齐，并保持同一水平基线。
- 标注线之间没有交叉。
- 引线落在控件边缘或边缘附近，不落在控件中心。
- 引线没有遮挡核心文案、价格、按钮文字、奖励数量或关键图标。
- 规则类内容已区分：交互规则留在主文档，程序 / 配置 / 支付规则放到补充或待确认项。
