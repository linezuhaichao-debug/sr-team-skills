# 01 宣讲会轻量模板

> 2026-09-07 新增（神话宝库交付复盘落地）。本模板是 `01_宣讲会交付.html` 的固定验收模板：**只约束内容边界与页面结构，不规定间距、字号、栏宽等视觉参数**；视觉参数由当轮审美决定，需要排版指导时才加载 `frontend-design` 技能，不强制每次读取。

## 参考优先级

1. 本模板（固定验收模板）
2. 用户当轮指定的参考样式
3. 两者皆无时：最近一次通过校验的历史 01

## 内容边界（红线）

- 只放**最终规则**：定稿口吻的交互规则、流程、界面状态与关键界面图。
- **禁止过程性信息**：确认编号（Q1/Q2…）、用户原话、"拍板 / 已确认 / 跟推荐"等过程措辞一律不出现——这些只存在于 02 交互回写文档的确认台账与 `manifest.confirmations`。
- 不放文本ID 清单（02 的职责）。
- 每个界面章节是"讲这个界面"的最小完整单元：讲解者只看本节即可开口。

## 页面结构

1. **封面区**：活动定位一句话 + 术语口径 + 主流程（分步、可换行的形式，不用单行长句）。
2. **章节导航**：锚点目录，覆盖全部章节。
3. **界面章节**（按玩家流程逐界面 / 逐状态一节）：
   - 节标题 = 序号 + 界面名（含状态）；
   - 左栏：该界面的**完整状态截图**（不裁局部、默认无标注）+ 图注（界面名 + 原型 Frame 名）；
   - 右栏：逐控件规则块（控件名小标题 + 规则正文：展示 / 点击 / 反馈 / 异常）；
   - 同一界面的通用规则放"默认状态"节，其余状态节只写差异，不重复；
   - 无参考图的界面：左栏用指路占位框（指向复用组件 / 包装文档），不留空。
4. **收尾**：全局红线（保底隐藏、口径同源、配置驱动等跨界面约束）。

排版原则（定性，不设数值）：规则块化不连排；图与文有明确呼吸间距；正文行宽收窄保证可读；界面章节较长时让左图在滚动中保持可见（常用手段：吸顶）。**长文滚动时图先消失、右侧还剩多屏文字，即视为布局失衡。**

## 轻量视觉冒烟清单（正式打包前，01 每次必检）

- [ ] 无破图（图片全部加载）
- [ ] 无文字溢出 / 重叠
- [ ] 无大段文字墙（规则已块化）
- [ ] 无明显布局失衡（含左图是否过早滚出视口）
- [ ] 章节导航锚点可用

发现问题修复后重检；**无需全页面逐屏验收**。`03_图例索引.html` 仅在模板变化、截图异常或真实问题出现时做同样目检。冒烟不替代 `verify_image_carriage.py` 机器校验。
