# sr-gdd-html 使用卡：评审宣讲 HTML

**职责**：把功能 GDD 重排成"能边看图边讲"的单文件 HTML——一个界面一节、左图右文、规则块化，截图 base64 内嵌、零外链，可直接投屏、可直接外发。只搬运不发明：规则与数值全部来自源 GDD，且源 GDD 要有界面清单。

**什么时候用**："出评审会用的 HTML"、"把策划案做成宣讲页"。

**怎么用**：

```
/sr-gdd-html <SR_WORKSPACE>\proposals\英雄升级功能优化_20260902.md
```

**产出**（`<SR_WORKSPACE>\proposals\`）：`<主题>_宣讲_<日期>.html` 与同名 `.content.json` 成对留档；决策记录落 `decisions\`。
