# sr-concept 使用卡：从创意到功能设计

**职责**：把一句话创意展开成可验证的功能设计——先出设计核三角报告（2~4 个候选方向，各带风险与验证方式），你拍板后展开完整功能设计稿，最后交 `sr-gdd-human` 出成稿。

**什么时候用**："我有个创意"、"想个新玩法"、"这个点子能不能做"。

**怎么用**：

```
/sr-concept 玩家可以回溯时间改写上一场战斗的结果
```

**产出**（`<SR_WORKSPACE>\analysis\`）：concept-triage（设计核三角报告）、feature-concept（功能设计稿）、sr-gdd-handoff（交接 JSON）；决策记录落 `decisions\`。
