# sr-gdd-human 使用卡：功能 GDD 成稿

**职责**：入口产出（sr-concept 设计稿 / sr-analysis 复刻规格 / 旧案）在这里第一次落成完整功能 GDD——**只有纯规则与设计，不含任何配置内容**，决策留痕在附录 A。这些规则是 `/sr-config` 派生配置字段的唯一依据；**定稿通过后本成稿归档废弃，后续修改直接改定稿**（三者分工见 `../gdd-pipeline.md`）。

**什么时候用**："写策划案"、"出 GDD"、"出设计提案 / 功能文档"、"出一份人类可读版 GDD"。

**怎么用**：

```
/sr-gdd-human 基于 英雄改造v0.2.xlsx 出一份人类可读的成稿
```

**产出**（`<SR_WORKSPACE>\` 下）：`proposals\<主题>_<日期>.md`；被定稿退回时另出 `_修订点.md`；决策记录落 `decisions\`。
