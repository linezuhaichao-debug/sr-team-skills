# sr-gdd-fix 使用卡：功能 GDD 定稿修改

**职责**：定稿之后的**唯一改动入口**——按共用撰写纪律（`../gdd-writing-discipline.md` 的 D1–D11）改已有定稿的规则、界面、范围、验收、配置对应与多语言文本；先做影响面扫描再最小编辑，不重跑整合。需要动配置表时调 `/sr-config`（后者改完顺手回写定稿 §4 / §6）。

**什么时候用**："改定稿"、"修订定稿"、"调一下定稿里的某处"、"定稿里这个规则要改成…"。

**怎么用**：

```
/sr-gdd-fix 把神话宝库定稿里每日次数从 3 次改成 5 次
```

**产出**（`<SR_WORKSPACE>\` 下）：定稿**原地更新**（`proposals\<主题>_<日期>_定稿.md`，维持唯一活文档）；改动清单**不单独落盘**，写进决策记录的 `decision_result.changes`（决策记录落 `decisions\`）。
