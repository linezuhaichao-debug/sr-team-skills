# sr-gdd-ai 使用卡：整合定稿（完整溯源版）

**什么时候用**："整合定稿"、"出正式版/完整版 GDD"、"带溯源的策划案"——主线上它是**定稿步**：把 sr-gdd-human 成稿 + 配置表变更整合成带证据溯源的最终版。也可以直接从旧案/配置表起步（"写策划案"且不需要先出可读版时）。

```
/sr-gdd-ai 基于 英雄改造v0.2.xlsx 出功能 GDD
```

裸 `/sr-gdd-ai` 会先要主题和输入材料。**主线路径的最低输入是 sr-gdd-human 成稿 + 配置表变更**（配置变更没有就说明由谁补）；**直接调用路径**没有哪份材料是硬性必须的，最低输入是主题 + 一段能支撑规则粒度的描述。材料薄不阻塞——会触发决议问答，把关键取舍列成清单请你逐条拍板，**不替你做设计取舍**。

**成稿后 Human Gate**：

| 选项 | 含义 |
| --- | --- |
| `approve` | 批准，决策记录落盘为 accepted |
| `approve_with_conditions` | 有条件批准（条件写进备注） |
| `request_missing_evidence` | 缺上游材料，先补 |
| `revise` | 打回修改 |
| `reject` | 否决 |

**产出**（`sr_workspace\`）：功能 GDD 落 `proposals\<主题>_<日期>.md`；决策记录落 `decisions\`。

与 sr-gdd-human 的分工：本 skill 带证据溯源、配置契约、治理引用。**主线顺序是先 human 后 ai**：human 版先出"只留规则与界面"的成稿，sr-config 落配置后，本 skill 再把设计稿 + 配置变更**整合成带溯源的最终定稿**。它也可以单独使用（如只有旧案、不需要先出可读版时，直接从本 skill 起步）。
