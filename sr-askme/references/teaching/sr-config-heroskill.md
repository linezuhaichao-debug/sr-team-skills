# sr-config-heroskill 使用卡：英雄技能配置

**职责**：把【小世界】英雄技能详细设计.xlsm 的技能按规范落到副玩法技能表（B008-副玩法技能表.xlsx），自动推导子技能 / 计算 / buff 行与 ID 引用链。**用户调用型**——只能由人输入 `/sr-config-heroskill` 触发，agent 不会自动接手。

**什么时候用**："配置弗莱德"、"把技能设计落到配置表"、"这把英雄技能配一下"（都需手动输入命令）。

**怎么用**：

```
/sr-config-heroskill 把弗莱德的技能配进 B008
```

**产出**（目标表同目录）：配置副本 `<原表名>-新增<日期>.xlsx`（不覆盖原表）、审查报告 `<原表名>-配置审查报告-<日期>.md`、变动行视图 `.xlsx`（供界面查看高亮改动）。
