# sr-config-heroskill 使用卡：英雄技能配置

**什么时候用**："配置弗莱德"、"把技能设计落到配置表"、"这把英雄技能配一下"。

把【小世界】英雄技能详细设计.xlsm 的某英雄技能按规范落到副玩法技能表（B008-副玩法技能表.xlsx），自动推导子技能/计算/buff 行与 ID 引用链，附 `diff`/`diffview` 改动对比与变动行视图。

**流程**：读设计文档 → 读配置规范（7 张表字段语义、枚举字典、ID 规则、雅典娜完整样例）→ `scripts/config_tool.py` 提取设计数据、逐英雄产出配置计划 → 写表（占位行改造是多数英雄的必经路径）→ 自检 + 生成审查报告。

**关键规则**：先查重再新增（占位行/完整配置/正常新增三种处置）；子技能/计算/buff ID = 技能 ID 去前两位 + 序号；百分比→万分比、秒→毫秒；伤害/治疗系数一律走技能计算表；每次写入后生成审查报告，存疑项逐条列出让用户核对。

**交付**：输出文件是副本（原文件名加 `-新增<日期>` 后缀），不覆盖用户原表；变动行视图 `univer_import` 进新 worktree 供界面查看高亮改动。
