# sr-gdd-review 使用卡：功能 GDD 定稿审查

**职责**：对 sr 系列产出的功能 GDD **定稿**做**只读审查**——结构骨架、撰写纪律（按 `../gdd-writing-discipline.md` 适用列）、数值落地标注、§6 配置契约与 §7 多语言文本、与成稿/配置表的整合一致性，出审查报告（`proposals\<主题>_<日期>_审查.md`）。**不改定稿**：修复转 `/sr-gdd-fix`（配置表问题转 `/sr-config`）。

**什么时候用**："审查定稿"、"检查策划案"、"review GDD"、"这份定稿能不能交程序"。

**怎么用**：

```
/sr-gdd-review 神话宝库
```

**产出**（`<SR_WORKSPACE>\` 下）：审查报告 `proposals\<主题>_<日期>_审查.md`。
