# 设计文档结构（【小世界】英雄技能详细设计.xlsm）

## Sheet: 英雄技能三阶设计（主数据源）

| 列 | 字段 | 说明 |
|---|---|---|
| A | 英雄 | 中文名，如"雅典娜" |
| B | 品质 | 红/橙…（配置表不用） |
| C | 武器 | 剑+盾/锤…（配置表不用） |
| D | RPG定位 | 如"护盾流不死主坦克"（判断技能风格用） |
| E | 技能Id | 9位技能ID，如 100794523 |
| F | 备注 | "英雄·X阶技能类型"格式 |
| G | 技能类型 | 战技 / 大招 / 被动 |
| H | 阶数 | 1/2/3 |
| I | 技能名称 | 如"圣盾裁决" |
| J | 技能效果描述 | 带 `<color=#e48b4a>` 富文本标签，关键词高亮即术语 |
| K | CD | 秒（已含公式） |
| L | 数值拆分效果 | 部分行为 `#N/A`；含富文本标记，与 J 列一样需清洗后解析 |
| M | CD | 数值版 CD（秒），可能是 #N/A |
| N | 目标个数 | 部分行有（部分版本缺失） |
| O | 注意 | 特殊说明，如"佩戴武器技能触发" |

每英雄通常 9 行：战技×3阶、大招×3阶、被动×3阶（个别英雄被动只有部分阶）。

数值来源只用主表的 J 列（技能效果描述）和 L 列（数值拆分效果）。富文本清洗规则见下。

## 富文本清洗

J/L 列含 `<color=#xxxxxx>`、`</color>`、`\n` 标记。去标记后再解析；`<color>` 包住的词是游戏术语（嘲讽/护盾/沉默/禁疗/无敌/燃烧…），通常对应一个 buff 或 impact 逻辑。

## 描述中的固定模式 → 配置动作

| 模式 | 配置动作 |
|---|---|
| 对N名/目标造成X%伤害 | 子技能：敌方扫描+伤害系数（计算表 X*100） |
| 并嘲讽/沉默/眩晕N秒 | 追加控制 buff 到 impactList |
| 恢复X%生命 | 自身治疗子技能（计算表 X*100）或治疗 buff |
| 获得X%最大生命值的护盾 | 护盾 buff（impactId=4，param=`1,0,计算ID,0`，计算ID 引用 X*100） |
| 伤害减免X%持续N秒 | buff impactId=1 param=`50593828,计算ID` |
| 攻击提升X% | buff impactId=1 param=`50593830,计算ID` |
| 持续N秒 | buff duration=N*1000 |
| 召唤… | buff impactId=14，详见 conventions.md 召唤段 |
| 每3次普攻… | 被动 triggerType=7 param=N |
