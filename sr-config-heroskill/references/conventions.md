# 副玩法技能表配置规范

文件：`B008-副玩法技能表.xlsx`（7 张表，INDEX sheet 是映射说明）。
所有表结构相同：第1行中文表头、第2行英文字段、第3行简写、第4行作用对象、第5行数据结构；**数据从第6行开始**。B列是主键 ID。`;` 结尾的中文表头表示 table 类型（逗号分隔多值）。

## 表清单与职责

| Sheet | 主键 | 职责 |
|---|---|---|
| 技能表现表 | 技能ID | 施法动作/特效/音效（表现层） |
| 扫描特效表现表 | 扫描特效id | 子技能的子弹/范围特效资源 |
| 主动技能表 | 技能ID | 战技/大招/普攻入口：CD、持续时间、目标类型、子技能组 |
| 子技能表 | id | 核心战斗逻辑：扫描方式、数量筛选、伤害/治疗系数、效果组 |
| 技能计算表 | id | 数值系数（type=2 百分比万分比；type=1 固定值） |
| 技能效果表 | id | buff 定义：名称、持续时间、impact 逻辑与参数 |
| 被动技能表 | 技能ID | 被动入口：触发逻辑、条件参数、子技能组 |

## 数据流（以雅典娜一阶战技 100794523 为例）

```
主动技能表: 100794523 | 雅典娜·一阶战技 | cd=6000 | skillTime=2000 | type=1 | radius=2 | level=2 | cutType=1 | subSkillList=79452301,79452303
子技能表:   79452301 | 雅典娜一阶战技-4敌方伤害并嘲讽 | activeDelay=0 | delay=1200 | scanType=3 | scanParam=3,0,5,60 | scanTypeFilter=1 | scanNumFilter=1,4 | scanForm=1 | hurtRatio=79452301 | impactList=79452302
子技能表:   79452303 | 雅典娜一阶战技-自身恢复10%生命 | delay=1200 | scanType=3 | scanParam=0 | scanTypeFilter=2 | scanForm=1 | healRatio=79452303
计算表:     79452301 | 雅典娜·战技-伤害550% | type=2 | baseValue=55000
计算表:     79452303 | 雅典娜战技-恢复10%生命 | type=2 | baseValue=1000
技能效果表: 79452302 | 雅典娜·战技-嘲讽，持续2秒 | name=嘲讽 | icon=icon | effectPos=1 | duration=2000 | overlayType=1 | maxOverlayCount=1 | buffType=0 | isControl=1 | impactId=21
技能表现表: 100794523 | 雅典娜·一阶战技 | animName=skill | effectName=fx_rpg_ZH_134283295_skill_01
```

## ID 规则

- 技能ID（主动/被动/表现表）：设计文档直接给出，如 `100794523`
- 子技能/计算/buff/扫描特效 ID：技能ID 去掉前两位 `10` + 两位序号：
  - `100794523` → 子技能 `79452301`、嘲讽 buff `79452302`、治疗子技能 `79452303`
  - 序号在同一"技能组"内递增，**跨阶复用不换号**：二阶战技 100794524 的伤害子技能是 `79452401`，但嘲讽 buff 沿用 `79452302`；三阶新增沉默 buff 才用 `79452502`
- 已存在的 ID 一律复用，绝不重复创建

## 各表字段语义（按写入习惯）

### 主动技能表
| 字段 | 语义 | 常用值 |
|---|---|---|
| cd | 冷却 ms | 战技 5000-6000，大招 16000-18000，普攻 1000 |
| skillTime | 技能动作时长 ms | 通常 2000（普攻 1000） |
| type | 选择目标类型 | 1=敌方单体/范围，2=友方/自身增益，3=治疗或辅助 |
| radius | 释放距离 | 近战2，远程/子弹6，治疗 3-20 |
| level | 释放优先级 | 大招 1，战技 2，普攻 3 |
| cutType | 打断类型 | 1 |
| subSkillList | 子技能ID列表 | 多段效果逗号分隔，按释放顺序 |

### 子技能表（核心）
| 字段 | 语义 |
|---|---|
| activeDelayTime | 施法前摇 ms，通常 0 |
| delay | 延迟生效 ms：近战 350-500，弹道/飞行 400-1500（=弹道飞行时间） |
| scanType | 目标扫描形式：**1=子弹(飞行物)**，**2=弹道(抛物线)**，**3=范围扫描(自身/目标点圆形)**，4=投掷，5=随机扫描 |
| scanEffectId | 扫描特效表现id → 扫描特效表现表（子弹/范围特效） |
| scanParam | 扫描参数，含义随 scanType 变化（见下） |
| warning | 是否绘制预警圈 1/0 |
| scanTypeFilter | 阵营筛选：1=敌方，2=自身，3=友方，4=友方(治疗) |
| scanNumFilter | `阵营,数量`：`1,4`=4个敌方、`1,6`=6个敌方、`0`=全部、`2,1`=自身1个 |
| scanForm | 落点形式：默认填 1（自身圆形）；佐伊式连发弹才填 table（如 `2,2500,5,1,500`，见主动表 L 列说明） |
| hurtRatio / healRatio | **填技能计算表 ID**，不直接填数字 |
| impactList | 技能效果表 buff ID 列表（伤害+控制：伤害系数另算，控制进这里） |
| 释放参数2(L列,table) | 特殊弹道参数：`2,2500,5,1,500`=扇形5连发（佐伊火箭），普通技能不填 |

**scanParam 语义（scanType=3 范围扫描时）**：`中心点,半径,是否跟随[,角度]`
- `3,0,5,60`：3=前方偏移5m?（雅典娜战技实测），有歧义时**模仿同类英雄的写法**并在报告标注
- `2,3,1` / `2,99,1`：2=以自身为中心，3=半径3m，99=全屏，1=跟随
- `1,3,1`：1=目标点为中心，半径3，跟随
- `0`：无参数（自身单体）
- scanType=1 子弹：scanParam=飞行速度(如 20/15/10,1)

### 技能计算表
| 字段 | 语义 |
|---|---|
| type | 2=百分比(万分比)，1=固定值 |
| baseValue | 550%→55000；10%→1000；15%→1500 |
| skillId | 关联技能ID（很多现有行没填，可不填） |
| LevelValue | 等级成长，副玩法一般不填 |

### 技能效果表（buff）
| 字段 | 语义 |
|---|---|
| duration | 持续 ms；-1=永久 |
| overlayType | 1=不可叠加刷新时长，2=可叠加 |
| maxOverlayCount | 最大层数 |
| buffType | 0=减益(控制/debuff)，1=增益，2=特殊(召唤/燃烧 dot) |
| isControl | 1=硬控（眩晕/沉默/嘲讽/石化/禁锢），0=其他 |
| impactId / paramValue | 见下表 |

**impactId 字典**（paramValue 逗号参数）：
| impactId | 效果 | paramValue 模式 |
|---|---|---|
| 1 | 属性修正 | `属性ID,计算ID`；50593817暴击率 50593819暴击伤害 50593820破防 50593822治疗加成 50593827技能伤害增加 50593828伤害减免 50593829生命上限 50593830攻击 |
| 2 | 眩晕 | 无参 |
| 3 | 真实伤害 | `固定值计算ID或0,百分比计算ID或0` |
| 4 | 护盾 | `1,释放者攻击计算ID或0,接受者生命计算ID或0,固定值计算ID或0[,碎裂子技能ID,碎裂子技能ID2]`；护盾持续=duration |
| 5 | 持续治疗 | `释放者攻击计算ID或0,接受者生命计算ID或0,每跳万分比,1` 例 `0,79452303,1000,1` |
| 6 | 中毒/燃烧(叠加dot) | `计算ID,每层万分比,0` 例 `79465501,1000,0` |
| 7 | 击退/拉人 | `方向,距离,速度,参数` 例 `-1000,1000,0,200` |
| 8 | 破盾 | `计算ID,对怪计算ID` |
| 9 | 吸血 | `计算ID,1=本次攻击/2=持续期间`；自身持续型增益例见织田信长 `79464601` param=`79464601,1` |
| 10 | 禁疗 | `计算ID` |
| 11 | 净化 | `清除个数` |
| 12 | 无敌 | 无参 |
| 14 | 召唤 | `召唤物配表ID,1,继承方式(1全/2攻防血/3部分),技能组ID,可否被攻击0/1,可否被治疗0/1,出生子技能,-1或死亡子技能` |
| 17 | 石化 | `减伤计算ID` |
| 18 | 沉默 | 无参 |
| 19 | 减速/加速 | `计算ID`（负=减速） |
| 20 | 免疫控制 | `0=全部,1=眩晕,2=冰冻,3=石化,4=沉默,5=减速` |
| 21 | 嘲讽 | 无参 |

buff 命名：name 列填中文术语（嘲讽/沉默/护盾/持续治疗/攻击提升…）；icon 没资源时填 `icon` 占位；effect 没资源时留空；effectPos 1/3 都常见。

### 被动技能表
| 字段 | 语义 |
|---|---|
| coolDownTime | 内置冷却 ms（进入战斗触发类常 10000-50000） |
| triggerType | 1=初始化(所有玩法)，2=初始化(竞技场)，**3=进入战斗状态**，4=血量低于阈值，5=暴击时，6=受到致死伤害，7=普攻N次后，8=上阵全队，10=友方技能施放后（param=监听技能ID列表） |
| triggerParam | 随 triggerType：4→`自身1/目标2,阈值万分比,可否重复0/1`；7→`次数N`；10→`技能ID,...`；其余多留空 |
| triggerChance | 触发几率万分比，10000=100% |
| subSkillList | 触发后执行的子技能 |

被动链路：被动技能表行 → subSkillList 子技能 → 子技能 impactList 挂 buff 或直接伤害/治疗。
属性型被动（常驻攻击+X%）：triggerType=3 + 子技能 scanTypeFilter=2 + impactList=[属性buff(duration=-1)]。示例行 1001 的做法是直接把多个 `属性ID,计算ID` 对写进 triggerParam（触发1专用），两种写法并存，**优先用子技能+buff 链路**。

## 扫描特效表现表

子弹技能：type=1，effectName=子弹特效，effectPoint=出手挂点路径（没资源留空）。
范围技能：type=3，effectName=范围特效，effectTime=循环时长(如5000)。
通用预警资源（可直接引用的现成 ID）：990201 圆形r1.5、990202 圆形r3、990203 圆形r3-3s、990301 扇形30°6m、990304 扇形60°6m、990401 矩形1x6、990402 矩形2x4。
没有合适资源时：范围类留空+报告标注，**不要编造特效路径**。

## 技能表现表

每个技能ID一行：animName 战技=`skill`、大招=`ultimate`、普攻=`attack`；effectName 的资源路径按英雄专属前缀（如 `fx_rpg_ZH_134283295_...`=雅典娜）——**没有把握就留空并标注"待表现配置"**，策划会补。

## 常用通用行（直接复用，不新增）

| ID | 用途 |
|---|---|
| 999901/999902/999903 | 通用近战/远程/治疗普攻子技能 |
| 999401 | 测试回血子技能（托尔被动等占位引用它） |
| 10001/10004 | 怪物通用系数 / 英雄通用普攻伤害系数 |

## 跨阶复用模式（重要）

以雅典娜大招为例：
- 一阶 100794526 → 子技能 79452601 → impactList=[79452601(护盾6s)]
- 二阶 100794527 → 子技能 79452701 → impactList=[79452601(旧护盾),79452701(新减免15%)]
- 三阶 100794528 → 子技能 79452801 → impactList=[79452801(护盾10s,新行),79452802(减免复用)]
规律：**效果本体不变→复用 buff；数值/持续时间变了→新 buff 行（但 paramValue 里引用的计算ID 可复用旧的）**。

## 常见陷阱

1. 子技能表 M/N 列填的是计算表 ID 不是数值——`hurtRatio=79452301` 而非 `55000`
2. buff 的 paramValue 是字符串逗号格式写入（table 类型）
3. 玩法通用系数（10001-10004）不要重复创建
4. 治疗子技能 scanTypeFilter=4 且 scanNumFilter=`2,1`（治疗友方），敌方伤害 scanTypeFilter=1
5. 普攻引用通用子技能（999901 等），不单独建子技能；专属普攻（佐伊子弹）才建
6. `扫描形式` L 列默认填 1；特殊弹道（连发/散射）才填 table
7. 子弹类子技能的 `scanEffectId` 指向扫描特效表现表的子弹行；英雄专属子弹资源不存在时留空待表现配置，check 对 scanEffectId 悬空只警告不阻塞
